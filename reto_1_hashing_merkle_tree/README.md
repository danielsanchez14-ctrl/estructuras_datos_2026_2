# Reto 1 - Hashing y Merkle Tree

## Descripción

Este folder contiene el primer reto no evaluable del curso de Estructuras de Datos. Su objetivo principal es practicar el uso de funciones hash y la construcción de un árbol Merkle para verificar integridad y estructura de datos.

## Archivos

- `reto_hashing_merkle_tree.ipynb`: notebook principal del reto. Aquí se desarrollan los ejercicios, pruebas y visualizaciones relacionadas con hashing y Merkle Tree.

## Objetivo

- cumplir los retos: 1) Encontrar clave por fuerza bruta, 2) Crear y mostrar árbol Merkle, 3) Crear la prueba de inclusión de Merkle.

## Uso

Abre el notebook con Jupyter o JupyterLab y ejecuta las celdas en orden para revisar la solución del reto.
